# math-228-phys-insprd-machine-learning
UC Irvine's graduate course (Math 228) on Physically Inspired Machine Learning.

Topics learned in this course includes 
* Introduction to Artificial Intelligence and Scientific Machine Learning
* Physics Informed Neural Networks
* BiLO: Bilevel Local Operator Learning
* ODIL: Operator Learning; Fourier Neural Operators; Spectral Neural Operators; Convolutional Neural Operators
